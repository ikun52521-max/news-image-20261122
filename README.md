A one-page newspaper front page that sums up the world news of Sunday
22 November 2026: Iran's drone and missile strikes on U.S. bases in
Bahrain and the tanker attacks near the Strait of Hormuz, the drone strike
that set the Russian cargo ship Sparta II ablaze in the Gulf of Finland,
and President Trump's call for an Iran deal that "could last 20 years" —
plus a briefs line covering COP31, Estonia's border closure, the UN
leadership race, and the post-UNIFIL Lebanon plan. Drawn from scratch in
Python with Pillow: masthead, two illustrated scenes, headlines, and
briefs, all laid out as a single 1024×1024 poster.

## Run it

```sh
python3 main.py
```

This writes `news.png` (1024×1024, deterministic — two runs produce
byte-identical output). No arguments, no network access.
